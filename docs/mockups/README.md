## C5 필사 완성 증서
- [certificate_compare.png](certificate_compare.png) — 두 안 나란히
- [certificate_A_book.png](certificate_A_book.png) — **A 종이**: 권 하나 (예: 창세기). 그 권의 판화를 아치 창에, 금빛 두 줄 테, 쓴 방식 비율, 첫 절, COMPLETUM 인장
- [certificate_B_bible.png](certificate_B_bible.png) — **B 흑단 금박**: 66권 · 구약 · 신약. 판화 넷 띠, 숫자 셋 (쓴 날 · 화첩 · 두루마리), 헌사
- 제안: 권 하나 = A, 구약 · 신약 · 66권 = B (큰 마침일수록 무겁게). 둘 다 PDF (A4 인쇄) + 나누기 카드
- 정할 것: 안 고르기 · 이름은 헌사의 이름 (없으면 빼기) · 문구
