# 1.2.0 에 모으는 것

1.1.0 (versionCode 1004) 다음 릴리즈. 쌓아 두었다가 한 번에 AAB 로.

## 들어간 것
- 앱 안 업데이트: 새 버전이 있으면 아래 한 줄 → 뒤에서 받기 → 다시 시작 (Play 설치본에서만)
- 새로 바뀐 것 화면: 업데이트 뒤 처음 한 번 · 설정 › 도움에서 다시 보기

- 새 앱 아이콘: 도레 「빛이 있으라」 판화 위 흰 선 라틴 십자 (정중앙) · 시작 화면 어둠 바탕 (`scripts/app_icon.py`)
- 나누기 카드 한 가지: 말씀 + 판화 (그 장 판화, 없으면 표지 판화). 발자취 · 한 해 카드도 같은 틀
- 위젯 셋 새 틀 (오늘의 절 · 이어 쓰기 · 내 손글씨)
- 나의 성경 PDF · 손글씨 PDF: 판화 표지 + 헌사, 라틴 머리글, 금빛 장 · 절 번호
- 내 목소리 영상 (평생권 · 구독): 세로 1080×1920, 판화가 천천히 다가오고 낱말이 목소리를 따라 밝아짐, 넘어가는 화면으로
- 여는 화면: 화첩에 건 판화 가운데서 날마다 한 점 + COLLECTIO 몇 번째
- 별점 부탁: 장을 마친 순간 Play 공식 별점 창만 (앞에 묻는 질문 없음, Play 정책). 세 장 뒤부터 · 30일 간격 · 세 번까지
- 낭독 미리 받기 화면: 권마다 칩 (미리 받기 · 용량 / 받는 중 / 기다리는 중 / ✓ 받아 둠 / 평생권), 여러 권 차례로, 무료 권 모두 받기, 와이파이에서만 (기본). 서재 · 설정 › 듣기에서
- 이어 듣기: 오늘 화면에 ‘이어 듣기 · ○○ ○장 · ○절부터’ (2주 안, 성경 듣기만)
- 듣기 미디어 알림: 알림창 · 잠금 화면 · 이어폰 버튼에서 이전 절 · 멈춤/이어 듣기 · 다음 절 · 끄기, 그 장의 판화가 앨범 그림. 앱 안 ‘듣는 중’ 띠에도 멈춤
- 꾸미기: 표지 판화 · 헌사 · 잉크 넷 · 머리글 라틴/한글 · 도장 · 앱 아이콘 넷 (평생권). 표지 색 · 옛 표지 넘김 화면 지움
- 앱 닫아도 낭독 받기가 계속 (포그라운드 서비스 · 진행 알림)
- 진도 따로 기억: 이어 쓰기는 마지막으로 쓴 절을 따라가고, 다른 장 · 다른 권에서 쓰다 만 곳은 오늘의 ‘쓰다 멈춘 곳’ · 서재 ‘이어 쓰던 책’에서 그 자리로
- 장 고르기: 다 쓴 장 = 금빛 테, 쓰는 중 = 쓴 만큼 금빛 호. 권 줄에 ✓ 다 씀 · 퍼센트, 기록 목차에 금빛 칸
- 기도 · 매일 알림 시각 휠 (오전/오후 · 시 · 분), 매일 알림도 분까지
- 구획 머리 (먹선 · 라틴 · 로마 숫자): 오늘 · 성경 · 기록
- 오늘 탭 절기 머리: 절기색 띠 (성탄 · 부활은 금박) · 옅은 절기 판화 · 제n주 · 다음 절기까지 · 절기 말씀
- 읽기 화면: 쓰다 멈춘 절에 금빛 리본, 장 첫 글자 금빛, 여백에 쓴 날
- 발자취 = 판화 메달 (얻은 것 세피아 + 금빛 두 줄 테, 아직은 석고 + 진행 호)
- 화첩을 권별 도록으로, 다 모은 권은 금박 제목 + 십자
- 장 마침 판화에 작은 COMPLETUM 인장, 어두운 화면에 종이 결
- 말씀 위젯 판화 바탕 (4×2 이상), 아침 알림을 펼치면 판화
- 오늘 말씀이 먹 번지듯 (하루 첫 열기), 계획 시트에 지나온 길
- 오타 표시 밝은 진홍 (성령강림절 색과 구별), 숫자 높이 맞춤, 누름 반응, 빈 화면
- 구독권: 월 · 연 · 평생 세 가지 (연 구독 새로), 잠긴 권은 자물쇠 + 한 줄 안내
- 성경 탭 찾기 칸을 돋보기 칸으로
