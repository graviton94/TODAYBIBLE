# 교회 단체 선물 (평생권 코드)

교회 · 소그룹에 평생권을 한꺼번에 선물하는 방법이에요. 앱은 그대로 두고, Play 콘솔의 **프로모션 코드**를 써요.

## 콘솔에서 (개발자)

1. Play Console → 하루의 성경 → 수익 창출 → 프로모션 → **프로모션 만들기**
2. 종류: 인앱 상품 → 상품 `lifetime` 선택
3. 코드 수 (분기마다 앱 하나에 정해진 개수까지 무료, 콘솔에 남은 수가 보여요) · 기한
4. 만든 코드를 CSV로 내려받아 교회 담당자에게 전달

## 받는 분께 (안내 문구)

> 하루의 성경 평생권 선물이에요.
> 1. 앱을 열고 **성경 → 잠긴 권 누르기 → ‘교회에서 받은 선물 코드가 있으세요? Play에서 쓰기’**
> 2. 코드를 넣으면 끝. 앱으로 돌아오면 평생권이 열려 있어요.
> (Play 스토어 앱 → 프로필 → ‘결제 및 정기 결제’ → ‘코드 사용’에서도 돼요.)

## 함께 권하면 좋은 것

- 주일 설교 노트 · 사순절 40일 계획을 교회 일정에 맞춰 함께 시작하기
- 한 해 끝에 ‘올해의 성경’ 카드를 단톡방에 나누기
