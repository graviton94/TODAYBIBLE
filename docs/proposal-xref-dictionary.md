## 1. 무엇을 · 왜

| | 관주 (관련 구절) | 성경 사전 |

## 3. 화면

### 관주
- **화면 이름은 「관련 구절」 (Related verses).** "관주" 는 문서에서만.
- **어디로도 넘어가지 않아요 (10/15 결정).** 읽던 흐름을 지키려고, 관련 구절은 그 자리에서 본문 전체를 읽고 닫아요.
- **읽기 화면 (성경 탭):** 절을 누르면 뜨는 띠에 **「관련 구절」** 을 더해요. 누르면 아래 시트:
  `관련 구절 · 창세기 14:18 · 5` → 줄마다 장절 + 그 절 **본문 전체** (앱의 개역한글 / WEB 그대로). 아래로 밀어 닫기.
- **필사 화면:** 쓰는 흐름을 끊지 않게 기본은 숨김. 머리의 ⋯ 메뉴에 「이 절의 관련 구절」 만.
- **판화 이야기:** HISTORIA 아래에 「이 장면의 관련 구절」 한 줄 (판화 절의 상위 3개). 누르면 그 절만 작은 카드로.
- 사전 풀이의 장절도 누르면 같은 작은 카드 (판화 링크 팝업과 같은 방식).
- 시안: docs/mockups/xref_dictionary_ko.png · _en.png (시안 2).
- 관주 자료는 절 번호 짝이라 **개역한글 · WEB · KJV 모두 같은 자료** 로 돼요 (절 나눔이 다른 몇 곳은 STEPBible 대조표로 맞춤).

### 사전
- 시트에 **「관주 · 사전」** 두 칸. 사전 칸에는 **이 절에 나오는 이름 · 땅 · 낱말** 이 저절로 칩으로 (예: 창 14:18 → 멜기세덱 · 살렘 · 떡과 포도주).
- 칩을 누르면 한 장짜리 풀이: **뜻 (이름 뜻) · 풀이 3~5문장 · 처음 나오는 곳 · 주요 장절 (누르면 그 절만 작게)**. 판화가 있는 인물이면 그 판화 작게.
- 성경 탭 찾기에 「사전」 갈래 추가 (낱말로 찾기 옆).

## 4. 한국어 사전 만드는 법 (핵심 결정)

공개된 한국어 성경 사전이 없어서, **"역사 속의 성경" 처럼 우리가 쓰고 검토** 해야 해요.

1. **표제어:** STEPBible TIPNR 의 인명 · 지명 각각에 대해, 그 이름이 나오는 절의 개역한글 본문에서 한국어 표기를 자동으로 맞춰 뽑기 (예: Melchizedek → 멜기세덱). 맞추기 어려운 것만 사람이 확인.
2. **범위:** 처음엔 **자주 나오는 인명 · 지명 600개 + 성막 · 제사 · 절기 낱말 100개** (예: 에봇, 속죄소, 유월절). 나머지는 이름 뜻 한 줄 (Hitchcock) 만.
3. **풀이 글:** Easton 을 바탕으로 우리말로 새로 쓰기 (번역 + 다듬기). 성경 인용은 지금처럼 본문 파일과 자동 대조. 확실하지 않은 연대 · 위치는 "학자마다 달라요".
4. **영어:** Easton 원문을 짧게 (3~5문장) 다듬어 그대로.

## 5. 크기 · 성능

| | 크기 (앱에 넣을 때) |
|---|---|
| 관주 (표 3+ · 절마다 상위 8) | 약 15만 쌍 → 이진 파일 약 **0.6MB** |
| 사전 한국어 700 + 영어 4,000 | 글 약 **1.5MB** (압축 전) |
| 원어 (나중) | 약 3MB |

모두 앱 안 · 인터넷 없이. 처음 열 때만 읽어 메모리에 올려요 (지금 본문 읽기와 같은 방식).
